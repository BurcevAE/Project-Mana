# MANA 2.7.0

Самоулучшающийся когнитивный агент. Работает локально на Windows: как
приложение с окном, как команда в терминале и как библиотека.

> **Номер версии пошёл назад — с 5.25.0 на 2.0.0, намеренно.** Линия 5.x
> нумеровала одномозгового агента поверх LLM, который рос наращиванием.
> Сейчас работает другая система: неизменяемое ядро, владеющее
> генератором задач, оракулом, скрытой выборкой и гейтами приёмки, и
> эволюционирующий когнитивный слой, который предлагает изменения, а ядро по ним
> выносит вердикт. Продолжать счёт с 5.25 значило бы утверждать, что второе —
> это поздний релиз первого. Все 56 модулей получили 2.0 одновременно:
> поколение — свойство системы, а не отдельной подсистемы. Внутри
> репозитория версии нигде не сравниваются численно, это строки для
> отображения; но всё, что снаружи упорядочивает релизы, прочтёт 2.0.0
> как более старое, чем 5.25.0 — это цена перенумерации.

Проект перестроен из «агента поверх LLM» в **открытую когнитивную
систему** — такую, которая может расширять пространство собственных
представлений, операторов и программ мышления, а не только перебирать
параметры внутри заданного пространства.

Центральный вопрос, на который проект должен ответить экспериментально:

> Может ли автономная когнитивная система сама обнаружить новый способ
> мышления, проверить его на независимых задачах, доказать преимущество,
> перенести на другой домен и встроить как часть собственной архитектуры?

Это **гипотеза, а не результат.** Ниже честно разделено, что уже
измерено, а что пока только построено.

## Быстрый старт

```bash
pip install -r requirements.txt

python mana_run.py --list-brains          # какие мозги готовы и чего не хватает
python mana_run.py --ask "Сколько будет 17 * 23?"
python mana_run.py --consensus 2 --ask "..."   # два мозга + степень согласия
python mana_run.py --decompose "..."      # разбить, решить на разных мозгах, собрать
python mana_run.py --paths-status         # где лежит состояние и песочница
python mana_run.py --interactive
```

Приложение с окном:

```bash
python serve_ui.py                # интерфейс в браузере, без сборки
python build_exe.py --windowed    # собрать MANA.exe
dist/MANA/MANA.exe --self-check   # проверить, что упаковка ничего не сломала
```

Мозги подключаются бесплатными ключами; мозг без ключа просто отсутствует
в пуле. `--list-brains` показывает, где именно взять недостающий.

| Мозг | Переменная | Доступ |
|---|---|---|
| `ollama` | — | локально |
| `groq`, `groq-qwen` | `GROQ_API_KEY` | бесплатный тариф, ключ вида `gsk_...` |
| `gemini` | `GEMINI_API_KEY` | бесплатный тариф AI Studio |
| `cerebras` | `CEREBRAS_API_KEY` | бесплатный тариф |
| `mistral` | `MISTRAL_API_KEY` | бесплатный тариф |
| `github-models` | `GITHUB_TOKEN` | любой GitHub PAT |
| `openrouter-free`, `openrouter-alt` | `OPENROUTER_API_KEY` | модели с суффиксом `:free`, разных семейств |
| `lmstudio` | — | локальный OpenAI-совместимый сервер, `MANA_ENABLE_LMSTUDIO=1` |
| `cloudflare` | `CLOUDFLARE_API_TOKEN` + `MANA_CLOUDFLARE_ACCOUNT_ID` | Workers AI |
| `deepseek`, `openai`, `openrouter` | соответствующие ключи | платно, выключены по умолчанию |

Веб-интерфейсы ChatGPT и DeepSeek намеренно не используются: это нарушает
условия провайдеров, ломается при каждом редизайне и ведёт к блокировке
аккаунта. Каждый мозг обращается к документированному API.

### Почему граница именно такая

MANA не должна иметь возможности улучшить себя, изменив механизм, который
объявляет её улучшенной. Это не формальность: аудит показал, что до
перестройки инвариант держался **случайно** — `BenchmarkSuite` жил в
`pipeline.py`, который ничто не защищало, и только то, что whitelist
самопатчинга содержал одну чистую функцию, удерживало агента от
собственного тестового набора.

Поэтому:

- `mana/core/` защищён **по каталогу**, а не по списку имён: файл,
  положенный туда, защищён с момента появления;
- функции `hidden_tasks()` **не существует** — единственный способ
  соприкоснуться со скрытым набором это `hidden_score(answer_fn)`,
  возвращающий агрегаты; задачи живут только внутри вызова;
- обращения к скрытому набору считаются, ограничены бюджетом и
  логируются: неограниченные запросы подгоняют скрытый набор через один
  только счёт;
- режим оценки выдаётся ядром и не может быть присвоен агентом.

**Честное ограничение**, записанное в самих модулях: в Python нет
приватности, решительный патч подделает что угодно. Граница даёт то, что
её пересечение — явное действие, попадающее в запись, а не однострочное
присваивание, выглядящее как обычное состояние.

и в этом их ценность:

- цикл с критиком проиграл прямой цепочке (0.33 против 0.50) при тройной
  стоимости, и ворота отклонили его по шести пунктам;
- при 10 наблюдениях лаборатория выдала **ноль гипотез**, корректно
  отказавшись предлагать механизмы для того, что ещё не измерено.

Аппарат существует ровно затем, чтобы такие вещи не проходили.

## Чек-лист перестройки

### Когнитивная архитектура

- [x] **Фаза 0 — Аудит.** [docs/MANA_COGNITIVE_ARCHITECTURE_AUDIT.md](docs/MANA_COGNITIVE_ARCHITECTURE_AUDIT.md): что реально эволюционирует, что только выглядит самообучением, четыре архитектурных конфликта.
- [x] **Фаза 1 — Измерение и граница.** Генераторы задач с вычислимым эталоном, скрытый holdout, который нельзя прочитать, точная арифметика в верификаторе. *Поднята на первое место относительно ТЗ: всё остальное оценивается через неё.*
- [x] **Фаза 2 — Ядро и геном.** Ворота приёмки с парной статистикой, транзакции с восстановлением после сбоя, `CognitiveGenome` с десятью мутациями.
- [x] **Фаза 3 — Программы и компилятор.** Программа как данные, компилятор возвращает список кандидатов, рантайм-интерпретатор поверх существующего агента.
- [x] **Фаза 4 — Self Model и разрывы.** Способности только из измерений, интервалы Уилсона, разрывы компетенции и знания, ожидаемый прирост информации.
- [x] **Фаза 5 — Лаборатория экспериментов.** Гипотезы из паттернов отказа, выбор по ожидаемой ценности, три условия остановки включая убывающую отдачу.
- [x] **Фаза 6 — Законы и контрпримеры.** Четыре статуса с автоматическим понижением, пробы, выведенные из самого закона.
- [x] **Фаза 7 — Перенос и новизна.** Удержание эффекта вместо да/нет, held-out отдельно от cross-domain; новизна по четырём каналам, где поведение весит больше структуры.
- [x] **Фаза 8 — Популяция кандидатов.** Сетка ниш (домен × полоса) с элитой в каждой, пул новизны как второй вход, покрытие как измеримая доля «расширенного пространства».
- [x] **Фаза 9 — Эволюция представлений.** «Представление недостаточно» стало вычислимым: доля противоречащих пар, которые словарь не различает; новое поле выводится из самих коллизий.
- [x] **Фаза 10 — Самогенерируемый curriculum.** Выбирает домен и сложность; задачи, ответы и оценка приходят из ядра, поэтому экзамен подделать нельзя. Свежий сид на каждый урок, продвижение по интервалу, а не по числу попыток.
- [x] **Фаза 11 — Исследовательский цикл.** Кластеризация отказов по структуре, распределение одного бюджета между измерением и экспериментом, транзакция на каждый шаг. Запускается сам, останавливается сам.
- [x] **Фаза 12 — Синтез способностей.** Подтверждённое открытие становится шаблоном программы в геноме, который компилятор выбирает для того среза, где механизм был доказан. Подтверждение — вторая независимая проверка на свежих задачах, потому что вердикт первого эксперимента принадлежит его собственной заявке. Способность, переставшая работать, отзывается.
- [x] **Фаза 13 — Контролируемая мета-эволюция.** Настраивает веса поиска (ранжирование разрывов, выбор эксперимента, каналы новизны) — те, что до сих пор были написаны от руки и ни разу не измерены. Четыре ограничения: до критериев приёмки не дотягивается (ядро отсекается по пути, а не по списку имён), судится теми же гейтами, оценивается по снятой неопределённости, а не по числу принятых заявок, и планка объявлена в исходнике до запуска эпизодов. Плюс защита от дрейфа: три подряд принятых изменения в одну сторону — стоп.
- [x] **Фаза 14 — Реальные единицы стоимости.** Вызов перестал быть единицей: время, токены, память, класс субстрата. `Evidence.cost` — вектор, который гейты по-прежнему не читают. Плюс счётчик активации: эксперимент, где параметр не прочитан или прочитан и отброшен, объявляется не результатом, а отказом судить.
- [x] **Фаза 15 — Мозг перестал означать LLM.** `verify_arithmetic` и `run_code` стали мозгами с субстратом `algorithmic`: работают без ключей, без сети и при `enable_llm=False`. Отказ вне применимости — отдельный исход, не отказ оборудования. Каскад ставит дешёвый субстрат первым, потому что его отказ бесплатен.
- [x] **Фаза 16 — Замкнутые петли.** Поиск по пространству операторов подключён: типобезопасный перебор, найденная цепочка становится оператором и участвует в дальнейшей композиции. Проверка мощности выводится из самого гейта. Принятая мета-политика пишется туда, откуда её читают, сохраняется и проверяется после рестарта.
- [x] **Фаза 17 — Brain Factory.** `BrainGene` в геноме, правило выбора механизма, сборка датасета с тестом на утечку скрытой выборки, отзыв мозга. Правило отвечает `algorithmic` для четырёх доменов из пяти — на этих задачах классическому ML места нет, и это находка, а не пробел.
- [x] **Фаза 18 — Версионированная скрытая выборка.** H0 заморожен (3 домена, канон), H1 добавлен (5 доменов, **переформулированные** задачи). Три состояния вместо двух: отсутствие домена — это `NOT_EVALUATED`, а не отказ. Число пар выводится из требуемой мощности, планка значимости не двигается.
- [x] **Фаза 19 — Структурные решатели и третья поверхность.** Решатели переписаны так, чтобы искать отношение и число, а не предложение. Третья поверхность написана ПОСЛЕ них и после этого код не менялся: `arithmetic` и `sequence` её проходят, `text_ops` и `logic` — нет, и это оставлено как есть.
- [ ] **Финальный приёмочный эксперимент.** Полная цепочка с перезапуском и проверкой, что найденная способность сохранилась.

## Что это НЕ решает

Пул мозгов расширяет то, **чем** MANA думает. Измерительный слой чинит
то, **по чему** оценивается её улучшение. Но:

- **Открытие пока не продемонстрировано.** Построен аппарат, который
  зафиксирует его, если оно случится, и честно скажет, если нет. Ни один
  закон ещё не достиг статуса `VALIDATED`.
- **Старый геном `PipelineSpec` всё ещё оценивается по 21 подстрочной
  задаче.** Новый измерительный слой существует, но эволюция пайплайна на
  него пока не переведена.
- **Бюджет вычислений — реальное ограничение.** Одна проверенная гипотеза
  по полной цепочке ≈ 3 600 вызовов; одно доказанное открытие — 5–20
  гипотез. При потолке бесплатных тарифов около 3 000 вызовов в сутки это
  недели прогона, а не часы.

## Разработка

```bash
python -m pytest -q          # 889 passed, 8 skipped
python mana_run.py --version # продукт + версии всех подсистем
```

Версия продукта объявлена ровно в одном месте — `mana/version.py`. Каждая
подсистема версионируется отдельно, и версия поднимается **вместе с
изменением**, а не потом; `tests/test_versioning.py` падает, если
продуктовая версия изменилась без обновления теста.

Два теста падают на машине без `sentence-transformers`/`sklearn` — это
предшествует текущей работе и относится к семантическому поиску.

## Близкие работы

Без заявлений о новизне. Идеи, которые проект объединяет, существуют по
отдельности: открытый поиск и давление новизны (Novelty Search,
MAP-Elites, POET), самогенерируемый curriculum, синтез программ из
операторов (DreamCoder и родственные подходы к library learning),
самоулучшающиеся агенты с воротами приёмки. Чего в этих работах обычно
нет и что MANA пытается сделать иначе: связать открытие оператора с
обязательной проверкой переноса на независимый домен и отделить механизм
объявления улучшения от того, что улучшается, — физической границей, а не
соглашением. Это гипотеза о полезности такой связки, а не утверждение о
её новизне.
